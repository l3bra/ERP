Новая партия:
Все поля редактируются прямо в таблице. В журнал попадают создание партии и изменение количества.
Правка строк журнала меняет только запись, остатки в Базе не затрагиваются.
Токен и сопоставления хранятся локально. МойСклад используется только для чтения; его данные не изменяются.
Точные совпадения названий подставляются как подсказки. Связь сохраняется после нажатия «Сохранить сопоставление».
