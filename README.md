# Склад

Локальное приложение для учёта складских позиций. Интерфейс работает в браузере, API построен на FastAPI, данные хранятся в SQLite, фронтенд — Vue 3 (сборка Vite).

## Запуск на Linux-сервере

Требования: Python 3.10+; Node.js 18+ и npm (только для сборки фронтенда).

Первый запуск (создаёт окружение, собирает фронтенд и запускает API):

```bash
python3 -m venv backend/venv
backend/venv/bin/pip install -r backend/requirements.txt
cd frontend && npm install && npm run build && cd ..
./start_server.sh
```

Дальше приложение доступно с любого устройства в локальной сети:

- из сети: `http://<IP-сервера>:8000/` (IP сервера можно посмотреть командой `hostname -I`);
- локально на сервере: `http://127.0.0.1:8000/`.

Сервер слушает все интерфейсы (`0.0.0.0`). Если на сервере включён файрвол ufw, откройте порт:

```bash
sudo ufw allow 8000/tcp
```

Хост и порт можно переопределить переменными окружения: `ERP_HOST=127.0.0.1 ERP_PORT=9000 ./start_server.sh` (по умолчанию `0.0.0.0:8000`).

`start_all.sh` делает то же самое одной командой: при отсутствии собранного `frontend/dist/` собирает его, затем запускает API.

`start_server.sh` запускает только API и не открывает браузер (серверный режим).

### Автозапуск через systemd

```bash
# скопировать проект, например, в /opt/erp и отредактировать пути в юните
sudo cp deploy/erp-warehouse.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now erp-warehouse
```

После перезагрузки сервера API стартует автоматически (тоже на `0.0.0.0:8000`); браузер не открывается.

### Разработка

API (порт 8000):

```bash
cd backend
../backend/venv/bin/python -m uvicorn main:app --reload --host 0.0.0.0
```

Фронтенд в режиме разработки (Vite, порт 5173; API-адрес по умолчанию вычисляется сам — `http://<хост-страницы>:8000`, CORS открыт). Чтобы dev-сервер был виден из локальной сети, запускайте с `--host`:

```bash
cd frontend
npm run dev -- --host
```

Для продакшена фронтенд собирается в `frontend/dist/` командой `npm run build`; собранные файлы раздаёт сам FastAPI (`/` и `/assets`). Если сборка отсутствует, сервер отдаёт прежний одностраничный интерфейс `frontend/index-legacy.html`.

## Функциональность

Во вкладке «Настройка» задаются адрес API, линейки и справочник цветов. Цвета можно разрешать отдельно для каждой линейки и убирать из её набора. Цвет можно полностью удалить из справочника: его привязки снимаются, но сохранённые позиции и история журнала остаются без изменений. Для новых и существующих цветов настраиваются RGB и прозрачность; имеющиеся цвета и их привязки сохраняются при обновлении.

Четыре визуальные темы переключаются в шапке приложения; выбор сохраняется в браузере. Размеры колонок и строк таблиц тоже запоминаются в браузере.

Последнее действие во вкладках «База» или «Журнал» можно отменить кнопкой ↶ или сочетанием `Ctrl+Z` (`⌘+Z` на Mac). История отмен хранится в локальной SQLite-базе и остаётся после перезапуска. При новом изменении после отмены предыдущие отменённые действия больше нельзя повторно отменить.

Во вкладке «МойСклад» можно сохранить API-токен, выбрать один склад и сравнить остатки. Локальные позиции суммируются по полю «Название» (цвет), независимо от линейки и партии; таблица содержит только позиции из «Базы». Товары МойСклад можно сопоставлять вручную; точное совпадение названий предлагается автоматически. Каждая запись сопоставления имеет постоянный UUID (`mapping_id`), который хранится вместе с ней и доступен через API. Сопоставления сохраняются отдельно в `backend/moysklad_mappings.json` и не удаляются при удалении позиции из «Базы». Скопируйте этот файл вместе с `backend/warehouse.db` для резервного хранения. Кнопка обновления перечитывает «Базу», список складов и остатки МойСклад; кнопка сохранения создаёт оформленный Excel-файл с датой скачивания, временем последнего обновления и чередующейся серой заливкой строк. В браузерах с поддержкой File System Access API открывается выбор места; в остальных файл загружается в папку загрузок, настроенную в браузере. API МойСклад вызывается только запросами GET: изменения в нём не выполняются. Токен хранится в локальной SQLite-базе проекта без шифрования. Используется [JSON API Remap 1.2](https://dev.moysklad.ru/doc/api/remap/1.2/).

В журнал записываются создание новой партии и изменения количества. Правки линейки, названия цвета, партии и даты, а также удаление строки в журнал не добавляются; ранее созданные записи сохраняются.

Несколько строк операций можно выбрать в последнем столбце и объединить их примечания в одну общую ячейку с кодом, ссылкой и текстом. Общее примечание можно изменить или разъединить; при разъединении индивидуальные примечания восстанавливаются. Объединение, правка и разъединение поддерживают отмену.

Разделитель «НОВЫЙ ДЕНЬ» создаётся автоматически в полночь, при запуске и обращении к журналу — не более одного на текущую календарную дату. Если сервер был выключен, разделители за пропущенные дни не создаются. Кнопка ручного добавления также проверяет, есть ли разделитель за сегодня, и не создаёт дубликат.

## Данные

При первом запуске API создаёт локальную базу `backend/warehouse.db`. Эта база, а также Excel-файлы с данными, исключены из Git и не публикуются вместе с исходным кодом. Делайте отдельные резервные копии базы, если в ней есть важные складские данные.

## Состав проекта

- `backend/main.py` — точка входа API.
- `backend/app/` — пакет приложения: `database.py` (подключения и схема SQLite), `models.py` (Pydantic-модели), `services/` (бизнес-логика: остатки, журнал, каталог, МойСклад, отмена), `api/` (роутеры FastAPI).
- `backend/moysklad_mappings.json` — локальный файл сопоставлений товаров (создаётся при первом сохранении/переносе старых сопоставлений).
- `backend/requirements.txt` — зависимости Python.
- `frontend/` — интерфейс на Vue 3 + Vite (`src/` — исходники, `dist/` — сборка, `index-legacy.html` — прежний интерфейс для совместимости).
- `Styles/` — изображения-референсы оформления.
- `start_all.sh` — сборка (при необходимости) и запуск приложения.
- `start_server.sh` — запуск только API без браузера.
- `deploy/erp-warehouse.service` — systemd-юнит для автозапуска API при загрузке Linux-сервера.
